REST Endpoints (in backend/hono.ts):
POST /api/auth/token/login - JWT login
POST /api/auth/token/register - JWT registration
POST /api/auth/token/refresh - Token refresh
GET /api/user - Get current user (requires Bearer token)
PATCH /api/user - Update profile
GET /api/clips - Clips feed with pagination
GET /api/clips/latest - Latest clips
GET /api/clips/trending - Trending clips (period: day/week/month/all)
GET /api/reels/latest - Latest reels
GET /api/reels/trending - Trending reels
GET /api/recent-uploads - Recent uploads ticker
GET /api/search - Search users, hashtags, games
Authentication Flow
Uses custom JWT (not Supabase Auth)
Access tokens: 7 days expiry
Refresh tokens: 30 days expiry (secret = JWT_SECRET + '-refresh')
Passwords hashed with bcryptjs (10 rounds)
Protected routes check Authorization: Bearer <token> header
